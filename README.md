## How I Build

- **Layered architecture** — `models → selectors → services → serializers → views`, enforced across every app; services are verbs, selectors are nouns
- **Domain-driven, extractable design** — bounded contexts with no cross-domain foreign keys, correlated through soft keys instead
- **Security-first defaults** — JWT rotation + blacklisting, SHA-256 hashed OTPs, per-scope throttling, a custom permission class that closes DRF's default read-access gap
- **Observability by default** — non-blocking structured logging with request-scoped context, a live health dashboard on every service, JSON output ready for ELK/Datadog/Loki
- **CI/CD as a gate, not a formality** — migration-drift checks, containerised test runs against the built image, and zero-downtime SSH deploys with retry logic
- **AI-assisted, human-owned** — I use Claude Code and Cursor as accelerators; architecture, system design and code quality stay mine, encoded in a hand-written `CONTEXT.md` on every repo
